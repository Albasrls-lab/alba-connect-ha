# Alba Srls – app per Home Assistant

Repository delle app di **Alba Srls** per Home Assistant OS.

| App | Descrizione |
|---|---|
| [Alba Connect](alba_connect/DOCS.md) | Assistenza remota Dolomiti Connect: tunnel WireGuard in uscita verso il concentratore Alba |

## Installazione

Home Assistant → **Impostazioni → Applicazioni → Store** → ⋮ (in alto a destra) → **Repository** → incollare l'indirizzo di questo repository → **Aggiungi**.
Poi cercare l'app nello Store e installarla. La configurazione la fornisce Alba.

Il codice non contiene chiavi né dati dei clienti: la configurazione di ogni impianto resta solo nella sua centrale.
